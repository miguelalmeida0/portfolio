# Portfolio experience

Branch: `art-deco-portfolio-experience`.

This implements the selected pistachio / plum / forest design: role and skills on arrival, Second Voice first, rounded paired writing panels, three expandable projects, and the real portrait in the contact section. Camera Harness is excluded from navigation, the CV, sitemap and case-study routing.

## Run and verify

```sh
npm ci
npm run dev
npm run check
npm run test:unit
npm run build
npm run e2e
```

The homepage is `/`. Case studies are `/work/second-voice-ai`, `/work/f24`, `/work/vigia`, and `/work/mirror-ai`. Supporting pages are `/cv`, `/story`, and the custom 404. `/work/ghostwriter` permanently redirects to Second Voice. `/portfolio.pdf` resolves to the committed, searchable PDF.

`src/lib/experience/projects.ts` owns project content; `src/lib/content/folio.ts` owns CV content. Rebuild the PDF with `node scripts/generate-cv.mjs` after CV edits (Python, ReportLab and DejaVu fonts required only to regenerate it).

## Responsive and motion behavior

- Content width is capped; typography and margins scale continuously.
- Below 820 CSS pixels the studio becomes Draft / Result tabs. All four author choices stay side by side in rounded controls, with the selected choice filled plum; the tone slider remains visible. The draft survives tab and project switches.
- Wider layouts display both writing panels. Project metadata moves alongside the title from 1200px.
- The portrait stays in its own footer grid column, with at least 48px of desktop headroom. Contact links never overlap it. The full name sits below a divider in normal document flow and wraps when needed.
- Expanding a project preserves the clicked heading's position; a new scroll gesture immediately cancels compensation.
- Result reveal, highlight sweep, author selection, button feedback, and once-only entry motion respect reduced motion. Hero content is readable immediately. Opening a project smoothly brings its heading to 24px below the viewport top; the destination follows accordion reflow, and user wheel, touch, pointer or keyboard input cancels the scroll. Reduced motion reveals it immediately. Closing preserves the clicked heading position. Product recordings autoplay as muted, inline loops when visible, without player chrome. Hidden projects and background tabs pause playback. Reduced-motion and Save-Data preferences retain the poster, and blocked autoplay leaves the poster visible.

## Second Voice integration

The default preview is explicitly labelled **Interactive sample**. Each author and mood combination uses an authored example. Arbitrary user text is never presented as AI-generated by that sample.

The live connection is implemented behind `PUBLIC_SECOND_VOICE_EMBED_ENABLED=true`. It requires the companion branch `feat/portfolio-studio-controller` in the Second Voice repository. That branch adds a version-2 parent/frame protocol to the existing embed route and reuses the existing CSRF, challenge, idempotency, allowance and budget pipeline. No model keys enter the portfolio.

## Hierarchy refinement

The content column is capped at 72rem. Hero and featured-project type stop at 4rem; other project names stop at 2.75rem. Rewrite text stops at 2.25rem and draft text at 1.5rem. Writing panels use content-driven height with a 26rem minimum, so longer writing can grow rather than being clipped. Controls retain 44px targets and the main action retains 48px.
