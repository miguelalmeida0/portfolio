# Anti-AI-Tell Preflight

Use this final pass for landing pages, portfolios, marketing pages, redesigns, and visual-heavy brand surfaces.

## Hard Bans

- no generic AI-purple / blue gradient default
- no safe AI-default muddy brown, dull charcoal, beige, grey-blue, orange accent, purple glow, terminal green, or neon lime palette in expressive modes without exploration
- no sepia/espresso/umber brown-black archive wash on pages, stages, cards, panels, notes, command containers, containers, sidebars, drawers, modals, or nav
- no nocturne/archive/field-guide/botanical/brass/tobacco/parchment/vintage/cinematic/commander/incident/operational/premium rationale for that same banned brown-black surface family
- no three equal feature cards as the default layout
- no endless centered sections
- no fake div-based screenshots
- no generic stock filler when real imagery is structurally needed
- no stock image used as factual product proof
- no generic names like `Acme`, `Nexus`, `SmartFlow`, `Cloudly`, `John Doe`
- no fake-perfect numbers like `99.99%`, `1234567`, `50%`, or fake spec precision
- no generic avatar eggs or default user icons as social proof
- no default `Inter` unless justified by the design read
- no serif-by-default for "premium" or "creative"
- no em-dashes in visible UI copy
- no decorative status dots unless they convey real semantic state
- no fake live/session chips
- no random mock values, generic app sections, or abstract business-free dashboard labels
- no `mission control`, `control room`, `command center`, `topology`, `traces`, or `system map` unless the product domain and data contract justify them
- no hero version labels unless the brief is explicitly launch-specific
- no section-number eyebrows like `001`, `INDEX`, or `No. 04`
- no scroll cues
- no duplicate CTA intent
- no CTA wrapping on desktop
- no logo walls made only of plain text wordmarks
- no logo labels below logo walls
- no photo-credit captions as decoration
- no prose-heavy hero stacks
- no giant text without a layout reason
- no decorative locale/time/weather strips unless the product is place/time dependent
- no decorative text strip at hero bottom
- no floating top-right tiny explainer paragraph in section headers

## Required Checks

- design read declared
- active dials declared
- strict 3-image direction gate completed for new visual-heavy work, or blocked fallback explicitly approved
- if Migi selected A, B, C, or a hybrid, the agent continued into build instead of asking for redundant implementation permission
- design system or aesthetic family selected honestly
- one page theme locked across the page
- one palette/accent system used consistently
- palette exploration documented for artistic, cinematic, landing, portfolio, creative, editorial, or experimental work
- one radius/shape system used consistently
- hero fits the first viewport
- hero text stack is limited
- trust/logos sit below hero, not inside hero
- each CTA has clear distinct intent
- every CTA passes contrast and fits on one desktop line
- visible copy is reread and scrubbed of generic phrasing
- Domain Content Contract exists for app/dashboard/product UI: real entities, pages/routes, route jobs, sample records, units/ranges/statuses/source labels
- real images, source metadata, and asset manifests are used where images are structurally needed
- meaningful images have accurate alt text, crop strategy, palette relationship, and text safe-zone notes
- motion is motivated and respects reduced motion
- advanced/cinematic/portfolio motion, when requested, has `docs/design/motion-choreography-plan.md`, named techniques, multiple motion layers, and evidence or a documented capture blocker
- mobile collapse is explicitly planned

## Mechanical Caps

- maximum 1 eyebrow per 3 sections
- max 2 consecutive zigzag image/text sections
- one marquee per page unless the brief explicitly calls for more
- section layout family should not repeat without strong reason
- default section copy: short headline, short paragraph, one visual asset or one CTA

## Output

Create or include an `Anti-AI-Tell Plan` in the visual spec:

- likely AI defaults for this task
- banned patterns
- how the design avoids them
- top hard checks before implementation
