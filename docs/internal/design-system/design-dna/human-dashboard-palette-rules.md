# Human Dashboard Palette Rules

Operational dashboards and command centers must not look like a default AI dark-mode template.

The palette must feel selected by a human designer for the product domain, user pressure, environment, and reference set.

## Required

- reference-driven palette rationale
- domain/environment fit
- task-pressure fit
- OKLCH/APCA contrast logic
- semantic surface roles
- state colors separated from decorative accents
- controlled accent use
- material range beyond one flat dark surface
- calm zones and busy zones
- screenshot comparison against approved dashboard references when those references are used

## Human Palette Signals

- neutral system has temperature and purpose, not only black/navy/blue-grey
- accents are assigned to actions, status, focus, and data roles
- status colors are restrained and readable
- panels have meaningful material hierarchy
- dark mode has depth and warmth/coolness decisions, not a single near-black canvas
- data colors are designed as a system, not random badge colors
- palette supports the primary task without turning into terminal furniture

## Hard Blockers

- dull robotic dashboard palette that immediately reads as AI-generated
- one-note dark navy/blue-grey surface system with blue outlines everywhere
- generic black/charcoal dashboard with a single cyan/blue accent as the whole identity
- terminal-ish panel spam when the product is not a terminal
- palette selected only because it looks technical
- palette not tied to approved references, product domain, or user state
- all cards, panels, nav, chips, and charts using the same dark surface weight
- status colors used as decoration instead of information
- elite dashboard references provided but palette ignores their material range and human color judgment

## Score Caps

- robotic AI dashboard palette: max score 5
- one-note dark surface plus single blue/cyan accent: max score 5
- dashboard palette has no reference or domain rationale: max score 6
- all dashboard surfaces share the same color/material weight: max score 6
- status colors feel decorative or arbitrary: max score 6
- approved dashboard references provided but palette ignores them: max score 5
