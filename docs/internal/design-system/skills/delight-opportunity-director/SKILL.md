# Delight Opportunity Director

Delight amplifies. It never blocks.

## Workflow

1. Name the product domain and seriousness level.
2. Identify the core task.
3. Find earned moments only.
4. Choose personality register.
5. Define what delight must avoid.

## Earned Moments

- first success
- completion
- empty state that invites action
- loading moment where perceived progress helps
- milestone
- safe recovery from error
- first-time onboarding step
- contextual easter egg that does not block work

## Registers

- calm premium
- playful consumer
- technical precise
- editorial human
- operational quiet
- celebratory
- serious trust-first

## Rules

- never delay core functionality
- never hide poor UX behind charm
- never distract from destructive or high-stakes actions
- never use random confetti for normal workflow
- domain seriousness controls the ceiling
- empty/error delight must preserve clarity first
