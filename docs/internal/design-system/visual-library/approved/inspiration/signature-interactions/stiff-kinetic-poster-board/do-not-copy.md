# Do Not Copy

Do not copy:
- exact brand name, logo, mascot, product, service, visual identity, or copy;
- exact palette, texture, illustration style, or iconography;
- proprietary animation timing, assets, media, or content;
- screenshots as production assets;
- brand-specific humor or claims.

Do extract:
- interaction sequence;
- spatial layout logic;
- motion role;
- information reveal model;
- accessibility fallback;
- scorecard failure signs.
