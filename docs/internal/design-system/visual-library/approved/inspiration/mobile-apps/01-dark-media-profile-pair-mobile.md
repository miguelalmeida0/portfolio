# Dark Media Profile Pair Mobile

## Status
Approved inspiration

## Visual summary
This reference shows two premium mobile screens side by side: a dark live-media browsing screen and a creator profile screen built around a large black-and-white portrait. The browse screen uses horizontal avatar rails, tall image cards, live badges, and a frosted bottom navigation bar. The profile screen turns the portrait into the main object and overlays identity, stats, and a gradient follow CTA in a dark translucent panel.

## What Migi likely likes
- Composition: paired screens show browse context beside a profile detail state, with the focal image doing most of the emotional work.
- Hierarchy: avatar rail, large media cards, profile name, stats, and CTA all have clear priority without flattening into a dashboard.
- Spacing: generous rounded cards and phone-edge breathing room keep the dense content readable.
- Typography: oversized profile type and bold card titles create instant scan value.
- Colors/materials: black, graphite, glass, soft glow, and a controlled rainbow gradient feel premium without becoming noisy.
- Interaction/product pattern: browse roster into profile/follow flow.
- Emotional tone: cinematic, social, nightlife, creator-led, and collectible.

## What future agents should copy
- Use a strong visual object or person as the first read, then layer product data in translucent panels.
- Pair selection/browse and detail states when explaining a product ecosystem.
- Use live/status chips as small supporting signals instead of letting metadata dominate the screen.
- Keep bottom navigation visually light when it floats over image-led content.

## What agents must not copy blindly
- Do not copy the casino framing, people, brand name, or exact profile identity.
- Do not reuse the exact gradient CTA as a generic decoration.
- Do not mistake phone chrome or mockup framing for product UI.
- Do not use image-led cards without real content provenance and asset hygiene.
