## Visual summary
This reference shows a planetary selection app with a dark list screen and a Mars detail screen. The selected object becomes a large hero focal point, while stats, secondary planets, and discovery controls sit around it in a dramatic black-and-orange composition.

## What Migi likely likes
- Composition: selection list and object detail form a clean roster-to-hero pattern.
- Hierarchy: the selected planet, title, and key facts take precedence over secondary navigation.
- Spacing: large negative space makes the hero object feel important.
- Typography: widely spaced labels and compressed display type create a sci-fi editorial tone.
- Colors/materials: orange/black contrast supports the subject without needing extra decoration.
- Interaction/product pattern: browse objects, select one, inspect facts, jump between related objects.
- Emotional tone: cinematic, educational, collectible, and exploratory.

## What future agents should copy
- Use a roster/list state that clearly leads into a single selected hero object.
- Give the selected object stable framing and enough breathing room.
- Keep secondary object thumbnails visible without stealing focus.
- Use subject-matter data as texture only after the main object reads clearly.

## What agents must not copy blindly
- Do not use planets or sci-fi tropes for unrelated products.
- Do not fake scientific facts or object data.
- Do not copy the exact Mars composition when the task needs different subject truth.
- Do not let decorative typography reduce readability.
