# Soft HR Productivity Dashboard System

## Status
Approved inspiration

## Visual summary
This reference shows a soft HR/productivity dashboard with employee metrics, progress cards, time tracking, calendar scheduling, onboarding tasks, and navigation pills. The visual system is light, warm, and dense without feeling like a default admin template.

## What Migi likely likes
- Composition: multiple dashboard modules fit into a single rounded canvas while keeping a clear reading path.
- Hierarchy: primary employee summary, progress, timer, onboarding, and calendar each have a defined zone.
- Spacing: soft gutters and rounded cards prevent the dense layout from feeling harsh.
- Typography: compact labels and large metrics support quick scanning.
- Colors/materials: cream, pale yellow, white cards, charcoal controls, and small yellow accents create warmth.
- Interaction/product pattern: dashboard navigation, progress review, time tracking, schedule inspection, onboarding checklist.
- Emotional tone: friendly, organized, calm, and operational.

## What future agents should copy
- Use warm operational dashboards only when the product truly needs repeated scanning.
- Group dense metrics into clearly bounded modules with different visual rhythms.
- Make the most important human or object context visible, not just charts.
- Use small color accents to mark progress instead of turning the whole UI into a chart wall.

## What agents must not copy blindly
- Do not build a generic SaaS dashboard when the task calls for a more specific product experience.
- Do not copy fake employee data, salaries, or HR labels.
- Do not use metrics unless the app can explain where they come from.
- Do not let dashboards replace the app's core loop proof.
