# Space Flight Booking Hero Desktop

## Status
Approved inspiration

## Visual summary
This desktop travel reference uses a full-bleed space/Earth hero, centered flight-booking headline, left-side route widgets, and a right-side glass search form. A visible browser/source overlay appears near the bottom, so that artifact must be excluded from any design interpretation.

## What Migi likely likes
- Composition: centered hero statement, functional side widgets, and booking form create a complete first viewport.
- Hierarchy: headline, CTA, route cards, and search form are visually separated without needing many panels.
- Spacing: wide desktop layout gives the hero image and controls room to coexist.
- Typography: large modern type makes the product feel high-end.
- Colors/materials: black/blue space background, bright blue CTA, glass form, and small luminous controls.
- Interaction/product pattern: choose trip type, enter route, search, inspect flight widgets.
- Emotional tone: premium, futuristic, aspirational, and cinematic.

## What future agents should copy
- Use the first viewport to show both emotional promise and the core product action.
- Keep the next functional section visible through side widgets or lower cards.
- Make the primary CTA obvious without drowning the screen in buttons.
- Use glass only where it reinforces a real control surface.

## What agents must not copy blindly
- Do not copy the brand, flight text, planet imagery, or browser/source overlay.
- Do not reproduce the visible "visit site" artifact or any browser chrome.
- Do not make every premium app a blue space hero.
- Do not add flight search behavior unless route/search data exists.
