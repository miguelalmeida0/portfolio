# Command Centers / Dashboards

Status: approved inspiration folder.

These screenshots teach Migi's dashboard direction. They are design evidence only, not production assets.

## What This Folder Means

Use this folder for Command Center / Dashboard Mode.

The direction is not "dark cards and charts." It is an image-aware, graph-rich, composition-led command surface with utility and visual memory working together.

## What To Extract

- attraction zone or focal visual/data anchor
- panel mix: metrics, charts, queues, tables, activity, media/object blocks, controls, actions
- chart forms and their decision purpose
- palette strategy and material range
- image/object/media roles
- live/state energy when relevant
- density level and visible content volume
- compact typography and calibrated containers
- soft premium surfaces, chips, segmented controls, and subtle depth
- contrast between calm zones and busy zones
- navigation restraint with understandable labels
- aligned search/filter/action toolbars
- scan-first panels instead of prose-heavy containers
- proportionate buttons
- collision-free responsive behavior
- layout integrity across 1440, 1280, 1024, 768, and 390
- chart bounds discipline
- semantic labels that do not collapse into fragments
- human palette direction, not machine-default color
- hierarchy without giant hero text
- route architecture that separates overview, analysis, decision, and action work instead of dumping every process into one page
- focused command surfaces where each route has a clear job

## What Future Agents Should Copy

- one memorable focal zone before arranging the dashboard grid
- varied panel sizes and functions
- useful charts integrated into the composition
- at least two meaningful visualization types when data supports it
- palette range with controlled accent use
- deliberate imagery, object, scene, avatar, media, map, or product visuals when they improve hierarchy
- mixed materials: base, raised, quiet, active, image/media, and data panels
- live indicators, progress movement, chart transitions, or state strips when the product represents activity
- compact but readable scale
- data, controls, lists, and visuals coexisting in one designed surface
- clear nav labels and crafted responsive navigation
- toolbar controls that share a clean rhythm
- buttons sized to their role
- panels that summarize state instead of burying users in prose
- dashboard structures that adapt at tablet/mobile instead of squeezing desktop columns
- chart components that stay inside plot/card bounds
- card and panel minimum widths that preserve readability

## What Agents Must Not Copy Blindly

- brand names, logos, exact colors, or proprietary imagery
- screenshots as production assets
- chart shapes without understanding what data or decision they support
- a dark theme just because several references are dark
- murky green/black terminal palettes unless a reference clearly supports them
- lime or any accent color sprayed across every element
- unexplained nav abbreviations such as `CMD`, `SIG`, `CMP`, or `BRF`
- fake live/session/status chips that do not affect decisions
- long full-width desktop buttons without layout justification

## Hard Avoids

- generic SaaS/admin templates
- same-weight card soup
- text-and-metrics-only dashboards
- murky monochrome dashboard palettes
- single-accent overuse
- terminal-ish dark panel spam
- decorative charts
- chart-lite dashboards despite graph-rich references
- no focal object or attraction zone
- image-starved dashboards when references show media/object anchors
- oversized empty dashboard cards and headings
- random image blocks that do not create hierarchy or memorability
- static dead dashboards for live/monitoring products
- cryptic navigation
- broken or cramped responsive nav
- misaligned toolbar controls
- text-heavy prose boxes
- oversized full-width buttons
- overlapping panels, chips, badges, or forms on resize
- text escaping containers
- chart bars/lines/points running outside their containers
- clipped card titles
- squeezed card garbage
- labels collapsing into `C`, `U`, `?`, or other meaningless fragments
- same desktop composition used at every size
- fake live/session/status theater
- machine-generated, robotic, dull palettes
- one-page information pileups where every process competes at once
- nav routes that exist visually but do not divide the work into focused jobs
- output that cites this folder but ignores its material range, palette judgment, attraction zone, and route focus
