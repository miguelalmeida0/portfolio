## Top Transfer Principles

1. Choose nav placement from the composition, not from habit.
2. Decide whether the wordmark is quiet identity, oversized structure, centered anchor, or spatial object.
3. Treat CTA placement as part of art direction.
4. For image-led pages, plan nav contrast and safe zones.
5. For portfolios, make Work/About/Process/Contact part of the experience.
6. For mobile, redesign the nav model instead of shrinking desktop links.
7. Let sparse nav stay sparse when the hero carries the experience.
8. Use oversized typographic navigation only when interaction remains obvious.
9. Keep focus, active, and keyboard behavior visible even when nav is artistic.
10. Do not use these screenshots as assets or brands to clone.

## Replaced Anti-Patterns

- default navbar gravity
- logo-left links-center CTA-right by default
- sticky pill nav as fake premium
- top nav pasted over an image-led hero
- generic portfolio grid with tiny top links
- desktop top link dump on mobile
- CTA detached from composition
- all direction options using the same navbar
