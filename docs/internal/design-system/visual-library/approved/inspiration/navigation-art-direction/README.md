# Navigation Art Direction

Canonical folder for approved navigation/art-direction inspiration.

These screenshots teach how navigation can become part of the brand world, spatial composition, and page rhythm. They are design evidence only, not production assets.

Use this folder when a future agent is designing:

- landing pages
- portfolios
- creative/editorial sites
- cinematic or image-led pages
- visual-heavy app shells
- mobile/product navigation systems that need more personality

## How To Use

1. Inspect the screenshots before choosing a navbar.
2. Pick the closest navigation pattern from `design-intelligence/navigation-patterns.json`.
3. Create `docs/design/navigation-strategy.md`.
4. Propose 3 distinct navigation concepts.
5. Select one pattern and document desktop, tablet, and mobile behavior.
6. Avoid default navbar gravity.

## Batch Lessons

- Navigation can frame the composition instead of sitting in a default top bar.
- A wordmark can be quiet, oversized, centered, cornered, or spatial.
- Contact/CTA can be a compositional anchor rather than a generic right-side button.
- Image-led pages need navigation safe zones and contrast discipline.
- Portfolio and creative sites can turn Work/About/Process/Contact into part of the layout system.
- Mobile behavior must be redesigned, not squeezed from desktop.

## Do Not Copy

- brands, logos, characters, certifications, product imagery, or proprietary layout details
- unreadable nav just because it looks artistic
- text over busy imagery without protection
- giant menu type that loses interaction clarity
- decorative dots or badges unless they belong to the product concept
