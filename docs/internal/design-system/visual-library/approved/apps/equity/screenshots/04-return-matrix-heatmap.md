# Return Matrix Heatmap

## Status
Approved app reference

## Visual summary
The screen shows a dense heatmap matrix of trailing returns and annualized CAGR by company and time horizon. Fixed company identity, numeric values, and colored cells combine into a compact cross-time comparison view.

## What Migi likely likes
- Composition: frozen identity columns beside a wide metrics matrix.
- Hierarchy: company rows and selected time columns make the table navigable.
- Spacing: tight grid cells are still readable because labels and dividers are disciplined.
- Typography: compact numeric type with clear ticker badges.
- Materials/colors: green/red heat cells, charcoal background, and thin grid lines.
- Interaction/product pattern: compare securities across horizons, inspect highlighted periods.
- Emotional tone: analytical, rigorous, and data-rich.

## What future agents should copy
- Use matrix views when users need cross-object and cross-time comparison.
- Keep the primary identifier fixed and visually stable.
- Highlight the active column without disrupting the whole table.
- Add formula/source notes below complex metrics.

## What agents must not copy blindly
- Do not copy returns, company names, formulas, or live data claims.
- Do not use heatmaps when users need narrative explanation first.
- Do not make dense matrices without responsive overflow strategy.
