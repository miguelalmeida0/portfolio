# Return Leaderboard Bars

## Status
Approved app reference

## Visual summary
The screen shows a return and CAGR terminal with a selected time horizon, summary metrics, and a ranked leaderboard with horizontal normalized bars. It turns performance comparison into a scan-first list.

## What Migi likely likes
- Composition: time selector and metric summary above a leaderboard.
- Hierarchy: selected horizon, best/worst/average/median, then ranked rows.
- Spacing: row height supports fast scanning without feeling cramped.
- Typography: large percentage values and compact ticker chips.
- Materials/colors: dark shell, green gain bars, red loss labels, subtle row dividers.
- Interaction/product pattern: switch time horizon, compare ranked names, click detail.
- Emotional tone: analytical, sharp, and performance-driven.

## What future agents should copy
- Put comparison controls directly above comparative results.
- Use horizontal bars for ranked magnitude when exact charting is not needed.
- Show summary stats before detailed rows.
- Make gain/loss semantics consistent across the product.

## What agents must not copy blindly
- Do not copy specific returns, tickers, or data source claims.
- Do not use dramatic gains/losses without explaining the calculation window.
- Do not rely only on color to communicate performance.
