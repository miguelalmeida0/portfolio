# Final Rewrite Output State

## Status
Approved app reference

## Visual summary
The screen shows the completed rewrite output with a clear output title, selected style label, copy action, and a button to open the rewrite lab. The input remains visible, making the transformation easy to compare.

## What Migi likely likes
- Composition: completed result is paired with the original input.
- Hierarchy: output title, transformed text, copy action, and next-step lab button.
- Spacing: the result card has enough room to feel final and calm.
- Typography: large serif result text fits the literary product.
- Materials/colors: dark panels, blue accents, subtle borders.
- Interaction/product pattern: inspect result, copy, open deeper review.
- Emotional tone: resolved, polished, and controlled.

## What future agents should copy
- Keep original and result visible after transformation.
- Give completed outputs clear copy/export affordances.
- Offer deeper analysis only after the primary result is shown.
- Label the selected mode/style beside the output.

## What agents must not copy blindly
- Do not copy author-specific claims or output prose.
- Do not add a "lab" if there is no deeper review experience.
- Do not hide the original input once the result appears.

## Best use cases
AI writing tool, output review, transformation workflow, editor, copy/export flow
