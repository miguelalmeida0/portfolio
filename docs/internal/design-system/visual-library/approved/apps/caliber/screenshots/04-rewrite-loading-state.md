# Rewrite Loading State

## Status
Approved app reference

## Visual summary
The screen shows the rewrite workbench while processing, with disabled rewrite buttons, a spinner, progress skeleton lines, and a message that the draft is being locked and read for the selected rhythm.

## What Migi likely likes
- Composition: loading state appears directly inside the output panel.
- Hierarchy: processing message, progress marks, then retained source input.
- Spacing: state feedback is contained without blocking the whole interface.
- Typography: loading copy stays in the same literary system.
- Materials/colors: blue outline and muted skeletons mark active generation.
- Interaction/product pattern: run action becomes disabled while the result is produced.
- Emotional tone: honest, calm, and observable.

## What future agents should copy
- Show processing where the result will appear.
- Disable actions honestly while work is in progress.
- Use loading copy that explains the specific operation.
- Keep the input visible during transformation.

## What agents must not copy blindly
- Do not copy author-specific processing claims.
- Do not use fake progress if nothing is happening.
- Do not over-animate loading states until they distract from the user's text.

## Best use cases
AI workflow, text generation, processing state, transformation tool, async action
