# Input Output Rewrite Workbench

## Status
Approved app reference

## Visual summary
The screen shows a two-column workbench with the user's sentence on the left and a live rewrite area on the right. Quick-start chips and primary rewrite actions sit below the input, while the output side starts as an empty waiting state.

## What Migi likely likes
- Composition: input and output panels are balanced side by side.
- Hierarchy: source text, quick starts, primary CTA, then output.
- Spacing: large panels make writing feel calm and serious.
- Typography: literary serif text inside work surfaces.
- Materials/colors: dark panels, subtle borders, pale blue action accent.
- Interaction/product pattern: paste/write text, choose prompt, run rewrite, copy output.
- Emotional tone: focused, calm, and workshop-like.

## What future agents should copy
- Put source and result surfaces next to each other for transformation tasks.
- Offer quick starts to help users test the loop.
- Make the empty output state specific about what will happen.
- Keep copy/export controls near the result panel.

## What agents must not copy blindly
- Do not copy sample text or prompt labels.
- Do not show a live rewrite panel if no generation/output path exists.
- Do not use a two-column layout on narrow screens without a responsive plan.
