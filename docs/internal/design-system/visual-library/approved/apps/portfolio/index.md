# Portfolio Approved References

Portfolio is an approved reference for authored identity, editorial pacing, and personal storytelling. Use it as evidence for calm, deliberate portfolio design, not as a universal product UI template.

## Reusable Patterns

- Lead with identity when the project is authored.
- Use oversized type and whitespace to create confidence instead of extra panels.
- Keep metadata quiet and useful.
- Make interaction metaphors truthful to the actual behavior.

## App-Specific-Only Patterns

- Miguel's biography, photo, contact details, and exact copy.
- The dark serif personal brand.
- Aviation/story details and timeline labels.

## Top Approved Directions

1. Calm editorial identity.
2. Copy-led hierarchy.
3. Structured long-form storytelling.
4. Quiet but designed contact intake.

## Warnings For Future Agents

- Do not turn product apps into portfolios.
- Do not copy exact personal identity elements.
- Do not use terminal styling without a real command or typing interaction.
