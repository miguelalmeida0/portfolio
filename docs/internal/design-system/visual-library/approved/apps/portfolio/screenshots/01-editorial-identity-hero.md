# Editorial Identity Hero

## Status
Approved app reference

## Visual summary
The screen shows a dark personal portfolio hero with a huge serif name on the left and a framed portrait card on the right. The navigation is small and quiet, while the identity, photo, and a few metadata labels carry the first impression.

## What Migi likely likes
- Composition: asymmetric hero with large type balanced by a framed visual object.
- Hierarchy: name first, portrait second, navigation and metadata third.
- Spacing: large negative space makes the identity feel deliberate and premium.
- Typography: oversized serif display type creates authored personality.
- Materials/colors: black background, white type, warm accent dot, and photo-frame treatment.
- Interaction/product pattern: portfolio landing with persistent section nav and theme toggle.
- Emotional tone: calm, intimate, editorial, and confident.

## What future agents should copy
- Make the first viewport signal the person or object immediately.
- Pair oversized identity type with one strong visual proof object.
- Keep navigation small when the hero is about presence, not task density.
- Use metadata as quiet texture instead of explanatory clutter.

## What agents must not copy blindly
- Do not copy the personal identity, portrait, exact name treatment, or red photo subject.
- Do not use giant serif type for operational tools.
- Do not copy the dark palette without an authored editorial reason.

## Best use cases
portfolio, personal site, editorial profile, founder page, authored case-study home
