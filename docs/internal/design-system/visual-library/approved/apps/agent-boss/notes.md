# Agent Boss

## Status
Approved app reference

## What Migi likes
- Enterprise control UI that is concrete about scenarios, authority, proof, risk, and verdicts.
- Dense side navigation paired with focused work surfaces, not generic admin cards.
- Status language that tells the truth: allowed, blocked, review, suppressed, proven, revoked.
- Evidence-oriented layouts with decision maps, queues, rollups, and action contracts.

## What future agents should copy
- For control products, make the current decision, owner, evidence, and next action visible.
- Use color for operational state, with text labels and explanation nearby.
- Build decision surfaces around real cases or scenarios instead of vague dashboards.
- Give dashboards a clear start-here task list when the product has many modules.

## What future agents must not copy blindly
- Do not copy the long side-nav taxonomy into unrelated apps.
- Do not use governance language unless the product has real policies, evidence, and authority.
- Do not copy refund/fraud/vendor examples as universal content.
- Do not copy screenshot crop bars or side overlay remnants.

## Scope
Global for enterprise control and governance workflows; app-specific for agent-policy domain language.
