Approved app reference

## Visual summary
The screen shows a tool gateway page with throughput charts, a verdict mix visualization, and execution boundary queues. It uses status lanes to separate allowed, held, and suppressed tool calls.

## What Migi likely likes
- Composition: throughput chart above lane-based queues.
- Hierarchy: reviewed status, chart pattern, then execution queue categories.
- Spacing: cards are broad and calm despite operational content.
- Typography: clear section titles with muted explanatory subtitles.
- Materials/colors: light canvas, white cards, green/red bar signals, thin borders.
- Interaction/product pattern: monitor calls, inspect queue lanes, review verdicts.
- Emotional tone: operational, stable, and controlled.

## What future agents should copy
- Use lane-based queues when operational items have mutually exclusive states.
- Put throughput context above action queues.
- Keep chart labels plain and close to the chart.
- Make operational review status visible.

## What agents must not copy blindly
- Do not copy tool names, queue items, or gateway language without matching product mechanics.
- Do not treat chart bars as decoration.
- Do not copy black capture bars or crop artifacts.
