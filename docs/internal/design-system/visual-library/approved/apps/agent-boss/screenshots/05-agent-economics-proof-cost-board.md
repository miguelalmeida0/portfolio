# Agent Economics Proof Cost Board

## Status
Approved app reference

## Visual summary
The screen shows a cost guidance signal board with cards for control cost, proof state, proof reuse, route simulation, and blocked cheap paths. Each card combines a small trend chart with a clear status explanation.

## What Migi likely likes
- Composition: two-column analytical board with focused card topics.
- Hierarchy: each card has one headline, one chart, and one state explanation.
- Spacing: generous gaps keep the board readable.
- Typography: strong card titles and status pills.
- Materials/colors: white cards, green/amber/red status semantics, soft shadows.
- Interaction/product pattern: compare route cost/control states and proof readiness.
- Emotional tone: sober, operational, and decision-supportive.

## What future agents should copy
- Give every analytical card one job and one state.
- Pair small charts with text that explains their consequence.
- Use blocked/ready/review statuses to prevent ambiguity.
- Keep multi-card boards organized around decision support, not decoration.

## What agents must not copy blindly
- Do not copy proof/cost language if the product cannot explain it.
- Do not add tiny charts without meaningful values.
- Do not use governance states as aesthetic badges.
