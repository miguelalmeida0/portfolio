## Reusable Patterns

- Make verdict, owner, evidence, and next action visible.
- Use status color with explicit text labels.
- Give every dense enterprise screen a clear current scope.
- Use scenario-based examples instead of vague dashboard summaries.

## App-Specific-Only Patterns

- Agent governance taxonomy and long sidebar structure.
- Refund, fraud, tool gateway, proof reuse, and authority language.
- Specific count values and policy examples.

## Top Approved Directions

1. Enterprise control plane with truthful state.
2. Evidence-first decision workflows.
3. Scenario and verdict surfaces.
4. Start-here guidance for complex systems.

## Warnings For Future Agents

- Do not copy long enterprise navigation into simple products.
- Do not invent governance status without underlying rules.
- Do not copy black bars, crop remnants, or side overlay artifacts from screenshots.
