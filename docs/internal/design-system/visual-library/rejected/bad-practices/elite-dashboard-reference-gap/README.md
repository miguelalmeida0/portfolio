# Elite Dashboard Reference Gap

## What Failed

Approved elite dashboard inspiration existed, but the result did not visibly absorb its lessons.

## Why It Hurts

The output can be clean and still mediocre. The goal is not merely no overlap; the goal is a command surface with human palette judgment, attraction zone, material range, useful visualization, and organized routes.

## How To Detect

- no memorable attraction zone
- no material range
- no human palette direction
- no useful graph hierarchy
- no focused command surfaces
- approved references are cited but not structurally transferred

## How To Fix

- pick 3-5 exact approved dashboard anchors
- assign each anchor a role: palette, composition, panel mix, route architecture, chart system, material range
- create reference decomposition and design transfer spec
- compare final screenshots back to the anchors

## Score Caps

- approved dashboard references provided but output ignores palette/material/routing lessons: max score 5
- command-center work has no attraction zone: max score 6
- output looks like generic generated dashboard despite references: max score 5
