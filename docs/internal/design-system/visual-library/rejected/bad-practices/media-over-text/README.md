# Media Over Text

## Bad Practice

- Video persists across the page without a clear reason.
- Video/image/media object overlaps text.
- Containers become skinny or unreadable because the layout is protecting the video.
- Cards lose their text integrity to accommodate media.
- A media-object signature interaction becomes more important than readable content.
- Scroll choreography forces media through content instead of moving content safely.

## Required Fix

- Keep video in the hero/top section by default.
- Or reserve a dedicated media lane.
- Or remove video after its stage is complete.
- Never let media sit on top of text.
- Never thin content cards to preserve a media object.
- Run layout-integrity-review.
- Run media-stage-review.
- Run screenshot-scorecard-review at required breakpoints.
