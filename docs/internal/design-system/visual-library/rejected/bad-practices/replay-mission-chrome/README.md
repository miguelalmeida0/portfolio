# Replay And Mission Chrome

Generic `Replay`, `Mission`, and `Mission Room` language is a recurring AI-made app tell.

## Why It Fails

It sounds cinematic while hiding weak information architecture. Real product routes should be named by the job they perform.

## Detect

- replay/mission labels in nav, hero, chips, or cards
- replay language in a static page with no replay control
- mission language used as page atmosphere

## Fix

Use Overview, Timeline, Traces, Services, Dependencies, Actions, Root cause, or Postmortem.

## Score Caps

- replay/mission chrome used as default identity: max score 4
- UI relies on AI-theater labels instead of real IA: max score 5
