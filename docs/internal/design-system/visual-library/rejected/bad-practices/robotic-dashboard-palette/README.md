# Robotic Dashboard Palette

## What Failed

The UI uses a dull, machine-default dark technical palette: near-black surfaces, blue-grey borders, cyan/blue accents, and generic status pills.

## Why It Hurts

It immediately reads as AI-created even when layout integrity is acceptable. Real dashboard art direction has material range, accent discipline, reference logic, and a palette that fits the product domain and user pressure.

## How To Detect

- one dominant dark/navy surface
- blue/cyan accent doing all identity work
- panels, nav, chips, and cards share the same material weight
- no reference palette rationale
- no OKLCH/APCA palette explanation
- no calm/busy color rhythm

## How To Fix

- derive palette from approved dashboard references and product domain
- define semantic surface roles
- use OKLCH/APCA to tune contrast
- assign accents by function
- create material hierarchy
- compare against approved dashboard screenshots

## Score Caps

- robotic AI dashboard palette: max score 5
- one-note dark surface plus single blue/cyan accent: max score 5
- no reference or domain rationale: max score 6
