# One-Page Dashboard Information Pileup

## What Failed

Too many processes are placed on one page when each should have a focused route, mode, or panel flow.

## Why It Hurts

The user must parse everything at once. The product feels like an AI-generated demo page instead of a tool designed around decisions.

## How To Detect

- many unrelated workflows visible in one scroll
- nav exists but the page still feels like one large pileup
- overview, timeline, services, traces, hypotheses, decisions, rollback, and mobile concepts compete together
- content density is not organized by task

## How To Fix

- create task inventory
- create route map
- give every route one primary job
- move detail into focused routes, drawers, or selected panels
- keep global context only where it helps

## Score Caps

- complex dashboard crams multiple workflows into one page: max score 5
- information architecture forces every process into one view: max score 5
