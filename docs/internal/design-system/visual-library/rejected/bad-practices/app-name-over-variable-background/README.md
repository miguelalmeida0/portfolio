# App Name Over Variable Background

## What Failed
The app name sits over an image, gradient, dark band, video, or changing background without a stable readability strategy.

## Why It Feels Weak
The app name may look fine in one crop and fail in the next. That is not art direction; it is luck.

## How To Detect
- Capture the app name across viewport widths and scroll positions.
- Inspect background changes behind it.
- Verify the brand text has stable contrast or an adaptive treatment.

## How To Fix
- Use a reserved brand surface.
- Add a plate/scrim.
- Switch foreground token by background state.
- Move or remove forced brand chrome.

## Score Caps
- app name unreadable over dark/variable background: max score 3
- brand chrome over variable background with no strategy: max score 4
- no brand chrome contrast proof: max score 5
