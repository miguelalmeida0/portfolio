# Navigation Responsiveness Failures

General rejected bad-practice evidence for nav labels overflowing controls, nav bars wasting space after resize, and nav systems with no responsive variant.

Canonical evidence:

- `../../case-studies/bunk-radio-text-container-nav-failures/screenshots/bunk-radio-04-nav-labels-overflow-items.png`
- `../../case-studies/bunk-radio-text-container-nav-failures/screenshots/bunk-radio-05-nav-resize-empty-space.png`

Rules:

- Nav label overflow is a hard blocker.
- Huge empty nav container at a breakpoint is a hard blocker.
- If nav labels hide, accessible labels must remain.
- Nav must define desktop, tablet, and mobile behavior.
