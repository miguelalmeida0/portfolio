# Process Failure

## Failure

The agent moved from requirements to full-page implementation before solving the hard visual problem: professional botanical illustration.

## Process Correction

For illustration-heavy work:

1. Run Illustration-First Gate.
2. Create isolated illustration assets.
3. Review the assets against reference grammar, linework, silhouette, and material quality.
4. Stop for Migi approval or explicit pass when approval is required.
5. Only then build the full page.

## Hard Stop

Do not call a run successful because all requested docs, mechanics, and sections exist. Success requires the hero visual asset to look good in isolation.
