# Signature Interaction Failure

## Failure

The Field Guide Plate Drawer mechanic existed in concept, but it did not create a memorable premium experience because the underlying visual assets were weak.

## Prevention

- Do not let a named mechanic pass if the visual execution is still amateur.
- Prove the hero asset first.
- Treat signature interaction as an art-direction outcome, not a checklist label.
- If the interaction relies on illustration quality, run an isolated asset-first test before page composition.

## Score Caps

- Signature mechanic exists only as a concept and does not visibly change the experience: max score 5.
- Signature interaction uses amateur illustration as its centerpiece: max score 4.
- Full page ships with weak hero asset because the mechanic was "technically present": max score 4.
