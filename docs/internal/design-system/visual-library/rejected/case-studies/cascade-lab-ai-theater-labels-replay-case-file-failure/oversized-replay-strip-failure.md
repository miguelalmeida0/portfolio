# Oversized Replay Strip Failure

The replay/root-cause/region strip looked like a generated dashboard artifact. It took prime screen space while adding little user value.

Metadata strips can work when they are compact, actionable, and tied to the current task. They fail when they become a decorative hero module.

## Rule

Prime page space must go to task content, not theatrical metadata strips.

## Score Caps

- oversized replay metadata strip: max score 4
- repeated status strip across pages: max score 4
