# Replay And Mission Chrome Failure

`Replay`, `Mission`, and `Mission Room` have become recurring AI-made app tells. They sound dramatic but usually do not map to a real product job.

In this case, they consumed navigation and page identity that should have been used for clearer route jobs such as Overview, Timeline, Services, Traces, Root cause, Actions, or Postmortem.

## Rule

Do not use replay or mission language as default chrome. Use it only when the user can perform an actual replay or mission workflow.

## Score Caps

- replay/mission chrome used as default identity: max score 4
- UI relies on AI-theater labels instead of real IA: max score 5
