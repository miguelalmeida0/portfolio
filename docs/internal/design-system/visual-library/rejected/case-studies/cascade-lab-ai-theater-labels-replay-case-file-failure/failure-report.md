# Failure Report

## Verdict

Rejected execution.

## Why It Failed

- The design used decorative incident-theater chips instead of useful product labels.
- `Replay` and `Mission` appeared as generic AI app language.
- The replay metadata strip took too much page space for a static artifact.
- The bottom of the page cut content, which is an amateur viewport failure.
- The `Case File CL-2049` label felt fake and robotic.

## What To Preserve

- Cascade Lab can still be a strong distributed-systems investigation product.
- Focused routes, readable process organization, and useful incident evidence are still the right direction.

## Required Future Prevention

- No fake narrative/replay/mission/case-file chrome.
- No fake severity badges unless severity is real product data.
- No large metadata strip unless it carries active user decisions.
- No viewport bottom cutoff.
- Anti-AI-slop review must search visible copy for these labels before handoff.
