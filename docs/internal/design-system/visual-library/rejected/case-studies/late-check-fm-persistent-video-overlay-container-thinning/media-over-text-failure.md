# Media Over Text Failure

## Bad Pattern

The video/image frame sits on top of readable card text and card surfaces that contain important content.

## Why It Is A Blocker

Readable text is the product interface. Media can add tone, but it cannot hide, cross, or compete with critical text.

## Critical Text In This Case

- Room names.
- Room prices.
- Event names.
- Event descriptions.
- Card labels.
- CTA text.

## Rule

Media may overlap decorative shapes, empty space, or its own frame. Media may not overlap text unless the text is intentionally inside the media with a dedicated readable surface.
