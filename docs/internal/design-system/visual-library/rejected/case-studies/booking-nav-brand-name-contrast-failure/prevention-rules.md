# Prevention Rules

## Navigation Active State Coverage
- Click every nav item.
- Edge items, including first and last routes, must become active.
- Use stable nav ids.
- Visual active state and aria/data active state must agree.
- Block handoff if any item can never become selected.

## Brand Chrome Readability
- App name, logo text, wordmark, and persistent brand chrome must remain readable over every background state.
- Variable, dark, image, video, and gradient backgrounds require a readability strategy.
- Use a plate, scrim, relocation, adaptive color token, or hide the wordmark.
- Block handoff if the app name struggles against the background.
