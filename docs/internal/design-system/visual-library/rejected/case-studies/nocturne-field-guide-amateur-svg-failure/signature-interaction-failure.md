# Signature Interaction Failure

## Failure

Nocturne had a visual premise but no signature interaction. It did not give the user an entry ritual, scroll route, plate drawer, specimen lens, or memorable motion system.

## Why This Matters

The provided references are not elite because of color alone. They are memorable because they each own a mechanic:

- kinetic poster board
- floating product stage
- editorial list detail panel
- portal object entry
- playful entry gate

## Required Future Rule

Every artistic, brand, portfolio, experimental, image-led, or award-reference landing page must either:

1. choose one signature interaction, or
2. explicitly justify why no signature interaction is appropriate.

## Nocturne Correction Options

- Specimen Lens Entry
- Field Guide Plate Drawer
- Annotation Ritual

## Score Caps

- award-level references provided but no signature interaction selected: max score 6
- generic section stack after signature references: max score 4
- static SVG illustration where the signature interaction requires animated reveal: max score 5
