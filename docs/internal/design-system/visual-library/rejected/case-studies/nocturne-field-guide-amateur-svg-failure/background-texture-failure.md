# Background Texture Failure

## Failure

Nocturne used a generic dot field and a vague light blob to make the surface feel textured and advanced. The result read as generated-app atmosphere, not art direction.

## Banned Defaults

- generic dot grid
- generic star field
- random noise
- vague glow blob
- soft spotlight haze with no source

## Allowed Texture Roles

- material paper texture
- photographic/grain texture
- meaningful field marks
- image-led atmospheric layer
- brand-specific pattern

## Rule

No generic dot grid, generic star field, random noise, or vague glow blob unless explicitly justified by reference mechanics and documented in the visual spec.

## Score Caps

- background reads as AI atmospheric texture: max score 5
- dotted/star-field texture as filler: max score 4
- light blob as generic atmosphere: max score 4
