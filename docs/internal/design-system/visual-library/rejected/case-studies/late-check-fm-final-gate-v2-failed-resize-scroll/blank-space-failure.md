# Blank Space Failure

Whitespace is only acceptable when it creates focus, rhythm, pause, or suspense.

Observed failure:
- Large blank regions appeared while content was clipped or offscreen.
- The blank area did not create a reward or intentional pause.
- It looked like a layout bug caused by scroll choreography.

Prevention:
- Blank scroll states require an intentional marker.
- Meaningful content must be present at each sampled scroll state.
- If the route strands content offscreen, simplify the route.
