# Viewport Edge Clipping Failure

Critical content may not be cut by the viewport edge at rest.

Observed failure:
- Giant type and room-board text are clipped by viewport edges.
- Panels appear as fragments instead of readable objects.
- The user has to guess or drag to understand content.

Prevention:
- Critical headings, cards, panels, nav, CTAs, and active scroll content must fit.
- Editorial type cropping is allowed only for non-critical text and only when documented.
- Horizontal routes must show active panels fully readable at resting states.
