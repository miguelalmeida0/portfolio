# Elite Dashboard Reference Gap

The approved dashboard inspiration is not just "dark dashboard with panels."

It teaches:

- a memorable attraction zone
- varied panel weights
- useful chart forms
- human palette direction
- material range
- compact but deliberate density
- calm and busy zones
- image/object/media roles when useful
- focused command surfaces

Cascade Lab did not show enough of that. It looked more like a competent generated operations page than an elite human-designed command center.

## Future Rule

When approved dashboard references are used, final review must compare the output against palette, material range, route focus, attraction zone, panel hierarchy, chart purpose, and density. If the result does not visibly inherit those lessons, it cannot pass.
