# Robotic Palette Failure

The failure is not that the UI is dark. Dark dashboards can be excellent.

The failure is that the palette feels automated: a near-black surface, blue-grey borders, cyan-blue headings, and status pills doing most of the visual work.

## Failure Signs

- one dominant dark surface family
- blue/cyan as the default "technical" accent
- little material range between nav, panels, chips, and content cards
- status colors that feel decorative rather than system-level
- no evidence of reference-driven palette selection
- no emotional or environmental fit

## Future Rule

For dashboard work, palette must be a designed system with surface hierarchy, state color semantics, reference rationale, and OKLCH/APCA contrast evidence.
