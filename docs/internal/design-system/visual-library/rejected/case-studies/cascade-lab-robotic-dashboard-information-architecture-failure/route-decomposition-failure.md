# Route Decomposition Failure

The navigation has labels, but the product still feels like a single stuffed surface.

## Better Direction

Each route should carry a focused process:

- Overview: incident summary, confidence, current action.
- Timeline: event sequence and causal moments.
- Services: dependency map and service ownership.
- Traces: span timing and comparison.
- Hypotheses: candidate causes and evidence.
- Blast Radius: affected users/systems and containment.
- Decision Log: decisions, owners, timestamps.
- Rollback Plan: action steps and safety checks.
- Postmortem: learning, follow-up, and unresolved questions.
- Mobile View: compact field/phone decision flow.

## Future Rule

If a dashboard nav item does not create a distinct route job, it is not information architecture. It is decoration.
