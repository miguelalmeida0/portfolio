# Compact Nav Failure

## Bad Pattern

The compact nav displayed arbitrary two-letter codes instead of recognizable destinations.

## Symptoms

- IN, WL, BD, NW, RL, and BK require decoding.
- The active state does not communicate the destination clearly.
- The nav resembles clipped labels.
- The compact state feels lower quality than the desktop state.

## Rule

Compact navigation must use icons, an icon + active-label pattern, a bottom nav, or a real menu/drawer. Two-letter abbreviations are not a design system.
