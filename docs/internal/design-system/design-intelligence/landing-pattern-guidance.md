# Landing Pattern Guidance

Use `landing-patterns.json` to match page structure to intent.

## Rules

- If Migi asks for artistic, creative, cinematic, editorial, or image-led, use poster logic first.
- Hero is not enough. The visual rhythm after the hero must still match the pattern.
- Landing pages need fewer elements with stronger intent.
- Do not default to feature-card rows unless the pattern requires them.
- Use image-first section references when visual quality matters.

## Visual Spec Requirements

- selected landing pattern
- hero architecture
- section rhythm
- copy density
- image role
- CTA strategy
- what pattern failures are avoided

## Blockers

- Blogspot/content-template layout
- artistic hero followed by generic card sections
- text-heavy landing page despite image-led references
- no image-first analysis when references/generation are available
