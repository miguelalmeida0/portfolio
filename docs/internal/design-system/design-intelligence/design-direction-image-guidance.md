# Design Direction Image Guidance

Use this for the strict 3-image direction gate.

## Prompt Structure

Every generated direction prompt should include:

- product concept
- selected visual mode
- palette direction
- typography direction
- layout/composition
- image/media direction
- navigation concept
- motion feeling
- what to avoid
- instruction: frontend design reference, not abstract art
- instruction: no fake broken UI text
- instruction: implementation-friendly

## Required Directions

- **A - Safe Refined:** polished, controlled, lower-risk.
- **B - Artistic Expressive:** more authored, more memorable.
- **C - Unexpected High-Character:** boldest, original, still usable.

## Mode Notes

- Landing: image-led, poster logic, sparse text, section rhythm.
- Dashboard: attraction zone, graph system, varied panel weights, compact readable density.
- Mobile: screen-first flow, safe areas, bottom nav for 3+ destinations, thumb-friendly actions.
- Portfolio: identity spine, project navigation as experience, media transitions.
- Creative: composition-led, unusual rhythm, fewer stronger objects.
- Editorial: typography, image/text rhythm, reading flow.

## How To Use Generated Images

Generated images are visual north stars. Extract composition, palette intent, typography mood, image role, navigation idea, and motion feeling. Do not copy broken text, fake logos, distorted UI, random noise, impossible layouts, or AI artifacts.
