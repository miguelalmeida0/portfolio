# Composition Originality Guidance

Use this when a visual-heavy page starts to look like AI-builder decoration instead of authored composition.

## Rejected Decoration

- Decorative circular/orbital/radar/HUD overlays.
- Fake sonar rings or generic orbit graphics.
- Large cropped circles used as cinematic filler.
- Decorative hairline separators, tiny red rules, label rails, and ornamental ticks.
- Forced logo/app-name/initials chrome added from template habit.
- Floating nav that becomes unreadable over images, giant type, or scroll-state background changes.

## Better Composition Tools

- Real image composition.
- Object-led layout.
- Full-canvas typography.
- Clean negative space.
- Material surface.
- Photographic atmosphere.
- Color field.
- Motion reveal.
- Functional chart, map, selector, progress ring, or labeled diagram when the geometry carries meaning.
- Editorial spacing and hierarchy.

## Required Questions

- Does this shape or line carry information, selection, navigation, progress, measurement, or structure?
- Would removing it make the design cleaner?
- Is this a repeated AI-builder motif?
- Is nav readable at the top, middle, and transition scroll states?
- Is brand chrome necessary, or is the main composition already carrying identity?

Default for Migi projects: no decorative orbit graphics, no decorative hairline filler, no forced brand chrome, and no unreadable floating nav.
