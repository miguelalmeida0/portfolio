# Elite Scroll Choreography Patterns

Scroll choreography is spatial authorship. The page changes as the user travels: objects move, context changes, information deepens, media transforms, and navigation tracks the journey.

Do not copy Stiff, Bucks Sauce, Wembi, Podium, Don’t Board Me, Bunk Radio, or any other brand. Extract mechanics only.

## Global Requirements
- Choose a named scroll pattern before coding.
- Create a route map and chapter map.
- Identify every pinned stage and moving object.
- Document what appears, docks, assembles, opens, or transforms.
- Define mobile and reduced-motion fallback.
- Run scroll choreography review after implementation.
- Run layout integrity review after scroll choreography review.

## Pattern Catalog

### 1. Scroll Route Choreography
Inspired by: Stiff

The page route moves horizontally, then vertically, then horizontally again. Content behaves like territories on a physical board.

Use when: award-level landing, portfolio, editorial, brand, playful product, or video-first page.

Avoid when: dense productivity tool.

Common failures: fade-in sections only; random parallax without route; no nav chapter sync; objects do not actually assemble; reduced motion removes content; scroll traps users.

## Hard Failures
- Elite scroll requested but only fade-in sections delivered.
- Selected pattern cannot be seen in the build.
- Pinned sections contain blank dead frames.
- Movement covers critical text or navigation.
- Horizontal desktop route has no mobile fallback.
- Reduced-motion fallback is missing or removes content.
