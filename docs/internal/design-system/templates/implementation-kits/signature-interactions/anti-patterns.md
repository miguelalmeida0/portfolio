# Anti-Patterns

- Award references used, but final page is a generic section stack.
- Portal/morphing promised, but implemented as a fade.
- Playful gate traps users or lacks skip/keyboard access.
- Mascot pasted in without a role.
- Reviews stay as plain quote cards after Review Theater was selected.
- Modal is a default dialog instead of part of the visual system.
- Scroll route has no route map or fallback.
- Signature interaction is decorative and does not create story, state, or decision clarity.
