# Signature Interactions Implementation Kit

Reusable recipes and dependency-light snippets for creating one memorable interaction mechanic. Use this kit after selecting a pattern with `skills/signature-interaction-director/SKILL.md`.

Rules:
- Extract mechanics, not brands.
- Use local state, CSS, SVG, and semantic HTML first.
- GSAP ScrollTrigger is optional only for scrubbed, pinned, or horizontal choreography.
- No paid APIs and no image generation.
- Always include accessibility and reduced-motion fallback.
