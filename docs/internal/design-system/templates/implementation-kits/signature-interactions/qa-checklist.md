# Signature Interaction QA Checklist

- Is one signature mechanic selected and named?
- Is the mechanic visible in screenshot or motion evidence?
- Does it support product/brand meaning?
- Is the core content reachable without the motion?
- Is there a reduced-motion fallback?
- Is there a keyboard or non-pointer fallback?
- Does it avoid copying reference brand assets?
- Does it avoid random scroll effects?
- Does it survive 1440, 1024, 768, and 390?
- Does it improve memory rather than slowing the task?
