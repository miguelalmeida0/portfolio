# Pattern Selection Guide

- Use Kinetic Poster Board for comedic, culture, studio, entertainment, or loud brand work.
- Use Scroll Route Choreography when the page should feel like travel through territories.
- Use Floating Product Ingredient Stage for tangible product truth.
- Use Scroll-to-Assemble Cards when the concept is chaos becoming order.
- Use Review Theater Cards when testimonials should become brand artifacts.
- Use Editorial List Detail Modal for light editorial tech and structured discovery.
- Use Portal Object Entry for cinematic portfolio or launch experiences.
- Use Media Constellation Stage for work grids and reels.
- Use Playful Entry Gate only when ceremony is acceptable and skippable.
- Use Mascot Hero Interaction when a custom character carries identity.
- Use Directional Page Transition when routes should feel like rooms.
- Use Service Ritual Selector for focused service/booking decisions.
## Nocturne Correction Patterns

- Use `Annotation Ritual` when the page needs professional field-guide/specimen annotation with protected labels.
- Use `Specimen Lens Entry` when a tiny moon mark, seed, dot, or lens can become the entry object.
- Use `Field Guide Plate Drawer` when specimen plates should organize from scattered/stacked artifacts into an archival guide.

Avoid static amateur SVG plates for award-level field-guide references. If the mechanic is only decorative illustration, choose another pattern or simplify the page.
