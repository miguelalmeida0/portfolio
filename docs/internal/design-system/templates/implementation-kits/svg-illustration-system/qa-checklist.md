# SVG Illustration QA Checklist

## Illustration-First Gate

- `docs/design/illustration-art-direction.md` exists.
- `docs/design/illustration-style-guide.md` exists.
- `docs/design/illustration-asset-options.md` exists.
- At least 1 isolated hero illustration component or SVG exists.
- `docs/qa/illustration-gate-review.md` exists.
- Full page implementation did not begin before the asset passed.

## Quality

- Reference grammar is extracted.
- Silhouette is strong.
- Linework strategy is visible.
- Detail budget fits the medium.
- Texture/material is specific.
- Botanical/organic forms meet the minimum bar.

## Safety

- Native Tooltip Ban is respected.
- Annotation Protected Zone is respected.
- No Ambient Background Blobs are present.
