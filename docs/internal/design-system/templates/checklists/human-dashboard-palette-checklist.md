# Human Dashboard Palette Checklist

Use for dashboards, command centers, incident tools, observability UIs, and operational products.

- Palette is derived from approved references or domain research.
- Product domain, user environment, and task pressure are documented.
- OKLCH/APCA contrast logic is documented.
- Surface hierarchy uses more than one material weight.
- Accent colors have assigned roles.
- Status colors are informational, not decorative.
- Dark mode avoids generic navy/blue-grey/cyan template language.
- Palette creates calm and busy zones.
- Final screenshots are compared against approved dashboard inspiration.

## Blockers

- robotic AI dashboard palette
- one-note dark surface with one blue/cyan accent
- no reference/domain rationale
- all surfaces share the same material weight
- status colors used as decoration
