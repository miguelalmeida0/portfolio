# Brand Voice As Interface Director Prompt

Use this when a playful, editorial, brand, hospitality, media, or creative interface needs copy that feels authored and useful.

## Inputs
- project path:
- protected folders:
- product type:
- audience:
- brand personality:
- current copy:
- user emotional state:
- safety/legal constraints:

## Required Output
- voice thesis
- vocabulary bank
- forbidden language
- CTA lexicon
- nav/card/detail/review copy strategy
- empty/loading/error tone rules
- before/after copy table
- clarity guardrails
- QA checklist

Hard bans: generic SaaS/hotel/template language, unclear CTAs, cute unhelpful errors, voice hiding product truth.
