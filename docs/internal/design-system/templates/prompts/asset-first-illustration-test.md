# Asset-First Illustration Test Prompt

Purpose: solve illustration quality before page composition.

## Inputs

- project path:
- illustration subject:
- reference grammar:
- style constraints:
- output format:
- responsive sizes:
- approval requirement:

## Output Only

- 1 to 3 isolated illustration components
- their style guide
- their QA review
- screenshots if possible

## Explicitly Forbidden

- full page layout
- navigation
- large background systems
- extra sections
- generic decoration
- ambient background blobs
- dot/star field atmosphere
- decorative orbit/HUD lines

## Pass Criteria

- asset looks premium in isolation
- silhouette is clear
- linework has intent
- detail system is visible
- material/texture is specific
- accessibility/decorative role is documented
- full-page build is blocked until asset review passes
