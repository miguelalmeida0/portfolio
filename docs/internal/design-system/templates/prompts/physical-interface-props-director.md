# Physical Interface Props Director Prompt

Use this when the interface uses tactile props such as labels, tickets, stickers, keycards, stamps, rails, pins, tabs, or cards.

## Inputs
- project path:
- protected folders:
- selected direction:
- prop references:
- product domain:
- copy lengths:
- responsive targets:

## Required Output
- prop inventory
- role for each prop
- material language
- text-fit strategy
- protected text zones
- layer/z-index plan
- motion behavior
- responsive fallback
- QA checklist

Hard bans: clipped prop text, props covering critical content, random decoration, sticker soup.
