# Unsplash Asset Manifest

Use `templates/unsplash-asset-manifest.template.md` for project-specific image sourcing.

Every selected Unsplash image must record:

- local filename
- local path
- Unsplash photo id
- source page URL
- download URL or download-location metadata
- photographer name and username
- description and alt description
- original dimensions
- dominant color and blur hash when available
- selected crop/orientation
- image role and section usage
- why selected
- palette relationship
- text overlay / safe-zone notes
- attribution and product-truth notes
