## What Review-Animations Adds

This is distilled from Emil:

- motion approval must be earned
- default to flagging questionable animation
- review only motion code
- cite file/line when possible
- use exact standards for duration, easing, reduced motion, performance, and physicality
- deliver a block/approve verdict

## What Impeccable Delight Guidance Adds

This is distilled from Emil and Taste mechanisms:

- delight belongs at earned moments
- personality must match domain
- success, empty, loading, milestone, error, and easter-egg moments can carry charm
- delight must never delay the core task
- delight cannot rescue unclear UX

## What Impeccable Animation Guidance Adds

This is distilled from Emil:

- one signature motion moment beats scattered motion
- motion communicates state, hierarchy, feedback, and continuity
- high-frequency actions should be instant
- reduced-motion is mandatory
- animation fatigue is a real cost
- performance budget matters as much as visual feel

## Mechanisms To Copy

- design read before coding
- one image per section for generated landing references
- zero em-dash preflight for visible UI copy
- hero, CTA, logo, eyebrow, section rhythm, image, and copy checks
- motion frequency table
- no ease-in for UI motion
- never scale from zero
- transitions over keyframes for dynamic UI
- reduced-motion and hover media-query gates
- Before / After / Why motion review table

## What To Reject Or Adapt

- Taste landing rules should not pollute dashboards or dense tools.
- High motion defaults should not be applied to high-frequency product controls.
- Imagegen requirements only apply when generating visual references or image-led landing pages.
- Motion delight should not become random ambient animation.
- Exact raw prompt text should stay in raw research, not become Design OS prose.

## Risks Of Blind Import

- animation fatigue
- landing-page rules incorrectly applied to dashboards
- preflight becoming a checklist theater instead of real craft
- every project using the same anti-AI-tell aesthetic
- overcorrecting into sterile pages with no personality
- treating generated references as production assets
