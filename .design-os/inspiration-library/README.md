# Inspiration Library

The inspiration library is a local evidence system for collecting, classifying, and safely using visual references.

It is not a production asset library.

## Folders

- `sources/`: trusted source lists and query packs.
- `screenshots/`: local screenshot captures. Ignored by git by default except `.gitkeep`.
- `manifests/`: manifest templates and examples.

## Rules

- Screenshots are local by default.
- Keep URLs and attribution notes.
- Pinterest is moodboard input, not award-quality proof.
- Do not bypass login walls.
- Do not scrape private or blocked pages.
- Do not commit copyrighted screenshots publicly unless Migi explicitly approves.
- Visual targets are evidence, not production assets.
