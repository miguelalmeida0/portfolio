# Recipe

1. Identify scroll-heavy segments and mark the story chapters.
2. Choose the lightest engine that can deliver the required route.
3. Decide which objects scrub with scroll and which animate after crossing thresholds.
4. Define settle points and snap only where it improves orientation.
5. Test wheel, trackpad, keyboard, and touch separately.
6. Create reduced-motion static storyboards.
7. Capture scroll samples and block blank frames, horizontal overflow, and text coverage.
