## Navigation Gate

The three directions must not all use the same navigation structure. If all three directions use the same top bar, the direction gate fails.

The gate also fails if nav readability is not discussed, app-name/logo chrome appears by default, decorative separator lines appear as filler, any direction uses decorative orbital/circular/HUD geometry without functional meaning and explicit acceptance, or mobile product directions omit modal fit, icon+label bottom nav, selection persistence, add-action differentiation, and control-indicator collision checks.

## Decision Needed

- Direction A
- Direction B
- Direction C
- a hybrid, for example `A palette + C composition + B motion`
