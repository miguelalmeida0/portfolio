## Motion Gate

Before implementation:

1. Name the exact motion references.
2. Create `docs/design/motion-choreography-plan.md`.
3. Choose a tool stack and explain rejected tools.
4. Specify at least five motion layers for advanced motion: page/section, image/media, typography, navigation/menu, micro-feedback.
5. Define reduced-motion behavior.

## Implementation Order

1. Implement structural layout first.
2. Add page/section choreography.
3. Add image/media choreography.
4. Add typography choreography.
5. Add navigation/menu choreography.
6. Add micro-feedback.
7. Add reduced-motion fallback.
8. Run build/lint if available.
9. Capture screenshots and motion sequence if possible.
10. Run animation review and scorecard.

## Final Response Contract

Report:

- motion references used
- motion-choreography plan path
- tool stack selected
- motion layers implemented
- reduced-motion behavior
- capture evidence or blocker
- animation review result
- remaining weaknesses
