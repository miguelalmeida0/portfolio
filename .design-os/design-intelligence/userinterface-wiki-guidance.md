# User Interface Wiki Guidance

Use this as a routeable craft lens, not a giant prompt dump.

## Best Uses

- broad UI review after the visual direction is known
- typography and numeric alignment checks
- press/active feedback checks
- pseudo-element layering checks
- predictive perceived-performance planning
- audio or sound feedback sanity checks
- UX law checks for grouping, target size, decision load, and state visibility

## Specialist Routing

- If the issue is palette or contrast, route `oklch-contrast-palette`.
- If the issue is motion code, route `review-animations`.
- If the issue is motion planning, route `motion-craft-director`.
- If the issue is final polish, route `make-interfaces-feel-better`.
- If the issue is art direction, route `frontend-art-director-review`.

## Hard Preferences

- Pressable things should feel pressable.
- Data-heavy numbers should align and scan.
- Motion should fit frequency of use.
- Audio needs mute and visual equivalence.
- Pseudo-elements should not carry critical semantic content.
- Perceived performance must never become fake status theater.
