# Agent Skill Layer Architecture

The next-generation Design OS skill layer is organized around a closed loop:

1. Session state remembers the creative context.
2. Orchestration chooses the smallest sufficient skill DAG.
3. Failure memory retrieves relevant rejected evidence before work begins.
4. Reference grammar and preference modeling define taste and transfer rules.
5. Responsive, interaction-state, and prototype-spike contracts prevent known high-risk failures before implementation.
6. Evidence-to-repair converts screenshots and detector findings into concrete fixes.
7. Artifact validation blocks false completion.

## Core Principle

Do not add more isolated checklists. Every new skill must either improve memory, route work better, prevent known failures earlier, turn evidence into repair, or validate that claimed completion matches artifacts.
