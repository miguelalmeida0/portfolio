# Tiny Invite Social Composer

## Status
Approved app reference

## Visual summary
The screen shows a social home page with a friend availability rail, a large invite composer, prompt chips, vibe filters, and a live plan preview below. A floating bottom nav keeps the main sections visible while the composer remains the primary action.

## What Migi likely likes
- Composition: people rail above one dominant invite composer.
- Hierarchy: invite action first, prompts second, live plan context third.
- Spacing: large rounded composer card with enough room for chips and input.
- Typography: heavy friendly headings paired with compact labels.
- Materials/colors: cream background, peach card, coral CTA, pastel chips.
- Interaction/product pattern: compose invite, choose vibe, send, then inspect live plans.
- Emotional tone: warm, low-pressure, social, and playful.

## What future agents should copy
- Put people/status context before asking the user to act socially.
- Use prompt chips to reduce blank-page friction.
- Make the primary send action obvious and singular.
- Show downstream live state below the composer.

## What agents must not copy blindly
- Do not copy friend names, profile images, exact plan copy, or location details.
- Do not fake who is nearby or available.
- Do not copy the bottom-left capture/control artifact.

## Best use cases
social coordination, invite flow, event planning, friend availability, lightweight composer
