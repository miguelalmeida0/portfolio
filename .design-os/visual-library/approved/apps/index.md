## Strongest Reusable Design Lessons

1. Primary object/action first: Atlas centers input, Ontime centers social action, Caliber centers transformation, and Equity centers scan/comparison.
2. State must be visible and truthful: Agent Boss verdicts, Ontime live plans, Equity recency/source labels, and Caliber process traces all show what is happening.
3. Dense UI is allowed only when the job needs density; Equity and Agent Boss justify it through scanning, evidence, and control.
4. Editorial calm comes from typography, spacing, and restrained accents, not empty decoration.
5. Transformation workflows need before, during, after, and why.
6. Selection-first flows work best when the chosen person/object has a stable detail surface.
7. Empty states should explain outcome and next action.
8. Color should encode semantic state, not become the whole design idea.
9. Strong visual identity must match product truth: literary for writing, terminal for finance, warm social for low-pressure planning.
10. Screenshot artifacts, browser chrome, overlays, watermarks, and Finder files are never product UI.
