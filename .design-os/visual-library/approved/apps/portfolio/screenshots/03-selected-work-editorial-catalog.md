# Selected Work Editorial Catalog

## Status
Approved app reference

## Visual summary
The screen shows a selected-work section with large editorial project cards in a dark layout. Each row combines a project title, tags, timeframe, short description, and a quiet call to action.

## What Migi likely likes
- Composition: broad horizontal project rows instead of cramped thumbnail cards.
- Hierarchy: project title and description lead; tags and dates support scanning.
- Spacing: large cards with generous internal padding make the catalog feel calm.
- Typography: serif project titles paired with letter-spaced metadata.
- Materials/colors: dark panels, thin borders, muted text, warm accent on section title.
- Interaction/product pattern: case-study list with readable summaries.
- Emotional tone: considered, mature, and archival.

## What future agents should copy
- Use row-based case-study cards when the work needs explanation.
- Put project meaning before decorative imagery.
- Keep tags small and supportive.
- Make the CTA quiet when the content itself is the draw.

## What agents must not copy blindly
- Do not copy the project names, years, tags, or case-study labels.
- Do not use this card style for dense products that need thumbnails or comparison.
- Do not assume dark editorial rows are right for every portfolio.
