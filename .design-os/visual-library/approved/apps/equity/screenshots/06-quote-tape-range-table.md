# Quote Tape Range Table

## Status
Approved app reference

## Visual summary
The screen shows a quote tape table with selected scope cards, rows for tickers, current PEG, price, move, off-high values, and 52-week range indicators. It emphasizes compact row comparison and range context.

## What Migi likely likes
- Composition: scope selector above a wide tabular quote tape.
- Hierarchy: ticker identity, price/move, and range position are prioritized by column.
- Spacing: wide rows support dense financial values without visual collapse.
- Typography: ticker badges and strong red values create fast scanning.
- Materials/colors: dark shell, green active bars, red price/move values, gray separators.
- Interaction/product pattern: switch quote scope, scan rows, compare range position.
- Emotional tone: operational, immediate, and market-aware.

## What future agents should copy
- Use range bars to explain current position relative to historical bounds.
- Keep the current scope visible above dense table rows.
- Use compact badges for repeated identifiers.
- Pair numeric moves with visual range context.

## What agents must not copy blindly
- Do not copy ticker names, prices, PEG values, or Yahoo/source labels as real data.
- Do not show live quotes unless recency and source are clear.
- Do not make all rows red/green without secondary labels or values.
