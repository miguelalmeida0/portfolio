# Inline Diff Rewrite Animation

## Status
Approved app reference

## Visual summary
The screen shows an active rewrite animation where old words are struck through and new words appear inline inside the output panel. A skip-animation button gives the user control over the pacing.

## What Migi likely likes
- Composition: diff action occurs inside the result surface.
- Hierarchy: transformed sentence is the main object, with skip/copy as supporting controls.
- Spacing: the output card isolates the animation from the input panel.
- Typography: large readable sentence text makes the change legible.
- Materials/colors: muted old text, blue insertion text, dark panels.
- Interaction/product pattern: animate transformation, allow skip, copy result.
- Emotional tone: transparent, crafted, and satisfying.

## What future agents should copy
- Make transformation visible when the process itself builds trust.
- Provide a way to skip animation.
- Use inline diff styling when exact text changes matter.
- Keep controls near the animated result.

## What agents must not copy blindly
- Do not animate text changes if readability suffers.
- Do not use diff styling for outputs where exact edits do not matter.
- Do not copy the sample sentence or author style.

rewrite tool, diff viewer, AI output review, content editor, transformation visualization
