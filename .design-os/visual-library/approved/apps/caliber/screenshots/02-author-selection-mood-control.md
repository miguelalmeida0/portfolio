# Author Selection Mood Control

## Status
Approved app reference

## Visual summary
The screen shows a rewrite controls interface with author cards, a selected state, a mood slider, and input/output panels below. It makes the user choose a voice before tuning the transformation.

## What Migi likely likes
- Composition: selection cards above a full-width mood control and workbench.
- Hierarchy: choose writer, tune mood, then provide input.
- Spacing: large horizontal cards make selection feel deliberate.
- Typography: serif cards and labels reinforce literary context.
- Materials/colors: black background, dark cards, pale blue selected card/accent.
- Interaction/product pattern: select voice, tune strength, write input, view output.
- Emotional tone: crafted, literary, and controlled.

## What future agents should copy
- Put selection controls before transformation controls when the selected mode changes the output.
- Make selected cards visually obvious.
- Use sliders only when the axis has clear meaning.
- Keep input and output panels visible near the controls they depend on.

## What agents must not copy blindly
- Do not copy author names or style claims.
- Do not use cards for options that do not materially change the output.
- Do not use vague mood axes without labels at both ends.
