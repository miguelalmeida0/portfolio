# Minimal Code Intelligence Input

## Status
Approved app reference

## Visual summary
The screen shows a minimal code intelligence home page centered around the question "What's broken?" and a large paste/repo input surface. A quiet left icon rail and small example chips support the primary input without competing with it.

## What Migi likely likes
- Composition: centered label, huge question, big input, and secondary examples.
- Hierarchy: primary action is unmistakable and everything else is quiet.
- Spacing: generous vertical whitespace makes the input feel important.
- Typography: large sans headline and mono helper text communicate technical focus.
- Materials/colors: off-white grid texture, black controls, green status accent.
- Interaction/product pattern: paste snippet or repo URL, choose examples, navigate via icon rail.
- Emotional tone: clean, focused, and confidence-building.

## What future agents should copy
- Center a single-action product around one dominant input.
- Keep supporting examples close but visually secondary.
- Use texture subtly so it does not become decoration.
- Make the input helper text concrete about what belongs there.

## What agents must not copy blindly
- Do not copy Atlas naming, example repo text, or code-analysis promise.
- Do not use this empty expanse for products that need browsing first.
- Do not copy the bottom-left capture/control artifact.
