## Visual summary
The screen shows a home dashboard with four system snapshot cards and a start-here task list. It uses simple status cards to identify what matters first, then presents three ordered tasks with clear buttons.

## What Migi likely likes
- Composition: snapshot metrics above an ordered task list.
- Hierarchy: the page tells the user which numbers to inspect and which tasks to run.
- Spacing: cards and task rows are spacious and easy to scan.
- Typography: large numbers, strong task titles, and concise descriptions.
- Materials/colors: light canvas, black sidebar, white cards, restrained status colors.
- Interaction/product pattern: inspect system state, start recommended workflow, open supporting checks.
- Emotional tone: clear, managerial, and action-oriented.

## What future agents should copy
- Use a start-here section when a complex app has a preferred workflow.
- Put task order and recommendation state directly on the row.
- Keep metric cards small and consequence-oriented.
- Use status pills to clarify action priority.

## What agents must not copy blindly
- Do not copy the governance task names or counts.
- Do not make a dashboard home if the product has one simple primary action.
- Do not use sample metrics as proof of real system state.
