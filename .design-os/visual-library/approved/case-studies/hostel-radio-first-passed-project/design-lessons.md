# Design Lessons

## Keep

- Concept-specific brand energy.
- Video-first hero when it has a clear role.
- Bold editorial/broadcast typography when it remains readable.
- Physical room/event card language.
- Fun copy that supports the product world.
- Mobile layout quality as a serious pass condition.

## Do Not Repeat

- Unsafe scroll choreography that breaks layout integrity.
- Media moving over text.
- Floating containers drifting across widths.
- Partial cards at viewport edges.
- Fake live labels.
- Misaligned backplates.
- Broken nav active states.
- Brand/app-name text that fades into a dark or variable image background.

## Rule

Readability and layout integrity beat visual ambition.
