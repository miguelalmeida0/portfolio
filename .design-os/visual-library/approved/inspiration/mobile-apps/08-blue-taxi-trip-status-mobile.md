# Blue Taxi Trip Status Mobile

## Status
Approved inspiration

## Visual summary
This reference shows a three-screen ride-hailing flow using a bright 3D yellow taxi as the repeated focal object. The states cover trip confirmation, waiting/countdown, and arrival feedback, all inside blue gradient mobile cards with translucent panels and clear action controls.

## What Migi likely likes
- Composition: the same object appears across states, making the flow feel coherent.
- Hierarchy: fare, route, driver, countdown, arrival confirmation, and feedback are cleanly prioritized.
- Spacing: large center objects and bottom action rows keep the screens touch-friendly.
- Typography: big price/status labels are balanced by small route and driver metadata.
- Colors/materials: saturated blue, yellow object contrast, glow, and soft glass panels create a friendly premium feel.
- Interaction/product pattern: call driver, edit trip, cancel, wait, rate after arrival.
- Emotional tone: playful, polished, approachable, and service-oriented.

## What future agents should copy
- Keep the focal object stable across multiple journey states.
- Use state-specific cards to explain what changed instead of redesigning every screen from scratch.
- Make primary trip facts visible before secondary actions.
- Let feedback/rating UI appear only after the product state justifies it.

## What agents must not copy blindly
- Do not copy the taxi model, brand, driver identity, or fake rating data.
- Do not use 3D objects if the app cannot provide consistent object assets.
- Do not add arrival/rating states before the core loop is proven.
- Do not let decorative glow reduce text contrast.
