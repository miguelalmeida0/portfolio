# Advanced Motion Sites

This folder stores motion-study references for award-level animated web work. These are not production assets and must not be copied as brand, layout, content, or visual identity.

Use this folder when Migi asks for advanced animations, cinematic motion, artistic motion, Awwwards/Godly/Recent-level motion, scroll choreography, portfolio motion, or motion like Graffico, Manet, UXBert, or Podium.

## How Agents Should Use These References

- Extract mechanics, not styling: reel states, menu states, pinned scroll, section handoffs, media reveals, typography motion, navigation choreography, and micro-feedback.
- Create `docs/design/motion-choreography-plan.md` before implementation.
- Name exact techniques instead of saying "smooth animation."
- Plan at least five motion layers for advanced work: page/section, image/media, typography, navigation/menu, and micro-feedback.
- Define reduced-motion behavior before coding.
- Capture a scroll-state sequence with `tools/capture-motion-sequence.mjs` when the app can run.

## Capture Status

The initial references were supplied by name in the motion upgrade brief. Full live animation capture was not performed in this pass, so `references.json` marks confidence honestly and records these as motion-study sources.
