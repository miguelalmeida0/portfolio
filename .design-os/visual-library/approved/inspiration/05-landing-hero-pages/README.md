# Landing Hero Pages

These references teach image-led composition and atmospheric landing-page behavior. They are design evidence, not production assets.

Use them to extract:

- dominant image or scene structure
- poster-like first screen behavior
- sparse copy and minimal UI chrome
- asymmetry, soft grids, or invisible grids
- visual rhythm that continues after the hero
- atmosphere, mood, and typography as identity

Do not use this folder as permission to create generic feature-section pages. A normal SaaS/blog/content-template structure with artistic images pasted into cards is a rejected direction.

When Migi asks for landing page, creative, artistic, cinematic, editorial, visual-heavy, image-led, landing-page inspiration, or creative inspiration, activate Landing Page / Artistic Mode before designing.
