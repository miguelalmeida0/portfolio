# Late Check FM Persistent Video Overlay + Container Thinning

## Verdict
Rejected execution, promising concept.

## What worked
- Gen-Z hostel / Late Check FM concept remains promising.
- Bold editorial room/event card direction is worth preserving.
- Video-first hero direction is worth preserving.

## What failed
- Video became a persistent overlay across the page.
- Media sat on top of readable content.
- Containers were thinned to make space for video.
- Text inside cards became awkwardly broken and unreadable.
- Layout was distorted to preserve a media gimmick.
- Scroll choreography hurt usability instead of improving it.

## Future prevention
- Video should be hero-only by default unless a later media state is explicitly justified.
- Persistent video overlays require a reserved media lane and protected text zones.
- No video/image/media may cover critical text.
- Never thin containers to fit media.
- Content containers must remain readable and content-aware.
- Media must leave the layout when its stage is over unless it has a meaningful reserved destination.
