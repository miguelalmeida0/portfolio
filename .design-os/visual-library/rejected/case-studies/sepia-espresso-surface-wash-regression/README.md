# Sepia Espresso Surface Wash Regression

## Why This Is Rejected

Migi explicitly rejected the muddy sepia/espresso/umber brown-black archive wash that keeps appearing in generated pages. This case study exists because the palette returned under a "nocturne field guide" concept: brown-black card surfaces, brass/cream strokes, botanical illustration, and archive language were used to make the same banned color family feel intentional.

That is not acceptable. Renaming the palette as nocturne, archive, field guide, botanical, brass, tobacco, parchment, vintage, cinematic, or premium does not make it usable.

## Failure Summary

- Main visual cards use the banned sepia/espresso/umber brown-black surface wash.
- Cascade Lab repeated the failure with a large "Commander Note" container, proving the ban must apply to operational panels and dashboard cards too.
- The palette reads like generated-app archive brown instead of authored art direction.
- Botanical/vector decoration is used to justify the same rejected color family.
- The dark surface competes with the otherwise stronger black/cream editorial direction.
- The result repeats a Design OS failure Migi already called out.

## Correction Principles

- Remove sepia/espresso/umber brown-black from major surfaces.
- Keep the strong black/cream editorial direction if it fits, but replace brown card surfaces with a distinct authored system.
- Use alternatives such as ink blue, aubergine-black, deep green-black, mineral grey, clean black/cream, cold moonlit blue, oxidized red, surgical green, chrome blue, or a reference-specific contrast-tested palette.
- Do not use "archive" or "nocturne" language to justify stale brown.
- If a direction generator produces this palette, stop and redo the palette before implementation.
