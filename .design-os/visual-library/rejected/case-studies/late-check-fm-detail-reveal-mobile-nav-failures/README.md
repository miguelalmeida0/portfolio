# Late Check FM Detail Reveal And Mobile Nav Failures

## Verdict
Rejected UX execution, promising visual direction.

## What failed
- Detail panel opened far away from the selected card.
- The trigger/detail relationship was visually broken.
- The user loses context after selecting an item.
- Mobile route navigation appeared at the top and disappeared on scroll.
- Mobile users lost access to primary navigation.

## Required future prevention
- Detail reveals must be anchored to their trigger or use an explicit full-screen/drawer pattern.
- Every trigger/detail relationship must be visually obvious.
- Mobile route/app navigation must be persistent and bottom-positioned by default.
- Scroll-heavy mobile pages must keep route navigation accessible while scrolling.
