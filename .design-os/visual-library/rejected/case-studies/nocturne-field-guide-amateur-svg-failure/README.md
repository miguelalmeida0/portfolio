# Nocturne Field Guide Amateur SVG Failure

## Status

Rejected.

## Summary

Nocturne Field Guide failed because it converted award-level reference ambition into static amateur SVG paperwork. It had decorative botanical shapes, annotation labels, dot texture, and motion language, but no memorable signature mechanic and no professional illustration system.

## Global Lessons

- Elite references are memorable because of signature mechanics, not nicer colors.
- A static SVG plate is not enough for an award-level landing page.
- Browser-native SVG tooltips break art direction.
- Annotation lines must never cross readable words.
- Dot fields and glow blobs are banned generated-app texture unless reference-justified.
- Shape skills must enforce visible outcome quality, not only produce planning artifacts.
