# Nocturne Field Guide Plate Drawer Failure

Rejected case study for the Nocturne Field Guide Plate Drawer rebuild.

This failure records a Design OS process problem: the implementation satisfied requested mechanics on paper, but the visual result still looked amateur because the illustration system was not proven before full-page composition began.

Screenshots referenced in Codex chat, not available to filesystem.

## Failure Themes

- Plate Drawer mechanic existed but did not produce a premium visual result.
- Botanical SVG work looked childlike and primitive.
- Field guide plates felt like vector doodles instead of professional specimen illustration.
- Large vague background blobs and ellipses read as generic AI atmosphere.
- The page felt requirement-driven rather than art-directed.

## Prevention

- Run the Illustration-First Gate before full-page implementation.
- Prove the hero illustration in isolation.
- Reject primitive botanical SVGs before composition.
- Ban ambient background blobs unless they are named, purposeful objects.
- Treat signature interaction as an outcome bar, not a checklist item.
