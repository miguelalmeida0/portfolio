# Oversized Metadata Strips

Large status strips that repeat shallow metadata are banned when they consume prime page space without decision value.

## Why It Fails

They look like AI dashboard filler. They make the product feel organized while actually displacing useful work.

## Detect

- big segmented strips near the top of every page
- metadata repeated as decor
- status strips larger than the content they support

## Fix

Make metadata compact, contextual, and actionable, or remove it.

## Score Caps

- oversized replay metadata strip: max score 4
- repeated status strip across pages: max score 4
