# Self-hosted hero fonts

Downloaded from Google Fonts on 2026-09-29. Latin WOFF2, normal style.
The site makes no runtime request to Google Fonts.

- Figtree variable (includes 400/600/700/800): https://fonts.gstatic.com/s/figtree/v9/_Xms-HUzqDCFdgfMm4S9DQ.woff2
- Antonio 700: https://fonts.gstatic.com/s/antonio/v22/gNMbW3NwSYq_9WD34ngK5F8vR8T0PVyW9itPaWE.woff2
- JetBrains Mono 400: https://fonts.gstatic.com/s/jetbrainsmono/v24/tDbY2o-flEEny0FZhsfKu5WU4zr3E_BX0PnT8RD8yKxTOlOV.woff2

Bundled licenses were retrieved from the corresponding `ofl/figtree`,
`ofl/antonio`, and `ofl/jetbrainsmono` directories of
https://github.com/google/fonts/tree/main/ofl .

Only the Figtree file is preloaded, on the homepage.

Newsreader 400 normal and italic, Latin WOFF2, downloaded 2026-09-30 for
