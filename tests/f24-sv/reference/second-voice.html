    Shipping it was not frictionless.

    Local verification and production readiness turned out to be different claims. The page states which one holds today.

    1. 136 tests verified at a milestone

      Verified

      Auth and sessions, quota rules, replay and idempotency, logout and revocation, and one real rewrite on Groq's free tier. Deployment readiness still waited on production checks.

    2. CI at 81 of 82

      Repaired and merged

      One security-environment expectation failed, and the install reported dependency vulnerabilities, one of them critical. Both were fixed and merged before moving on.

    3. 29 September 2026: the public app opens

      Live generation unverified

      A sample live rewrite returned Request blocked. Until that is resolved, live generation is not claimed as production-verified, and this page uses prepared examples.

    Built with

    Next.js, React, TypeScript, server routes, Supabase, Zod and Playwright.

    Sign-in

    GitHub OAuth with PKCE, HttpOnly verifier and session cookies, fixed callback origins, durable sessions, revocation and stale-cookie cleanup. No anonymous generation.

    Provider calls

    Bounded reads, cancellation, a deadline of about 30 seconds, zero automatic retries and one model call per operation. Ambiguous operations stay reserved instead of running again.

    Output

    Validated against a schema before it becomes product state. Generative output is treated as untrusted input.
