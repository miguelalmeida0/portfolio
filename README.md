# Portfolio

A production-ready SvelteKit portfolio starter built with TypeScript, Tailwind CSS, and a centralized token system.

## Quick Start

```bash
npm install
npm run dev
```

## Available Scripts

```bash
npm run dev
npm run build
npm run preview
npm run check
```

## Editing Content

Update your narrative, project entries, and contact details in:

- `src/lib/content/portfolio.ts`

Update the design system and reusable utility bundles in:

- `src/lib/design/tokens.ts`
